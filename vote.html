How to Join ApexSMP

HOW TO JOIN: JAVA EDITION
  • Open your Minecraft Java Edition launcher and start the game.
  • Head into the MULTIPLAYER menu from the main screen.
  • Click the ADD SERVER button located near the bottom right.
  • Set the server address field to: apexsmp.bbmc.fun
  • Hit DONE, choose the server from your list, and press join!
HOW TO JOIN: BEDROCK EDITION
  • Open Minecraft on your Bedrock device (Console, Mobile, or Windows).
  • Tap Play and switch over to the SERVERS tab at the top right.
  • Scroll all the way to the bottom and click ADD SERVER.
  • Enter apexsmp.bbmc.fun as the server address.
  • Ensure the server port is set to the default: 25573
  • Save the server, select it from your list, and connect!

Steps can differ slightly depending on your specific console or platform. If you run into any issues connecting, please open a support ticket right here in our Discord!
